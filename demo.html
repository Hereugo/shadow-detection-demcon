How it works
We detect a pedestrian without biometric data, using the shadow footprint as a proxy geometry signal. The model predicts a bounding box that may be off-screen (negative or beyond the image width).

In evaluation mode we compute:
- IoU = intersection / union using raw pixel coordinates (including negatives).
- Direction bonus: +0.05 if correct, -0.05 if wrong, 0.00 if missing.

Render trick: the canvas is expanded by 300px on each side. We shift all X coordinates by +300 when drawing, so off-screen boxes remain visible.
